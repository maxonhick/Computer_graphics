# Computer Graphics Algorithms & Raster Benchmarks

Коллекция программных реализаций фундаментальных алгоритмов компьютерной графики на **C++17** с использованием **SFML 3** и бенчмаркингом производительности с **OpenCV**.

## 📌 Содержание репозитория

В репозитории представлены практические реализации базовых задач растеризации, геометрического отсечения, алгоритмов заливки и интерактивного тестирования:

| Файл | Назначение | Ключевые алгоритмы |
| :--- | :--- | :--- |

## 🔬 Ключевые алгоритмы и особенности

### 1. Генератор фрактала Минковского (`squareKochIsland`)
Для создания стресс-теста алгоритмов заполнения используется фрактал Минковского (Minkowski Sausage / Island).
* **Свойство постоянной площади:** Каждый направленный сегмент делится на 4 части, создавая симметричный выступ наружу и впадину внутрь идентичной площади. Суммарная площадь фигуры на любой итерации строго равна площади исходного квадрата.
* **Экспоненциальный рост ребер:** На $k$-й итерации количество ребер многоугольника возрастает как $4 \times 8^k$ (на 5-й итерации — более 130 000 ребер), что кратно увеличивает число точек пересечения для горизонтальных линий сканирования.

### 2. Сравнение алгоритмов заполнения (`main.cpp`)

1. **Кастомный Flood Fill (Заливка с затравкой):**
   * Работает через классический BFS с использованием очереди `std::queue<Point>`.
   * Сложность зависит исключительно от площади фигуры $O(S)$. Нагрузка по времени остается постоянной (~25 мс) независимо от сложности контура.
2. **Кастомный Scanline Fill (Построчное заполнение с AEL):**
   * Построение таблицы ребер (`Edge Table`) и поддержание списка активных ребер (`Active Edge List`).
   * Сортировка пересечений по чет-нечетному правилу. При росте числа ребер до 16 384 время выполнения возрастает из-за необходимости частой сортировки массивов пересечений на каждой строке.
3. **OpenCV `cv::floodFill`:**
   * Промышленная оптимизация: интервальная заливка полосами (**Scanline Span Flood Fill**) + векторизация **SIMD (Apple Silicon NEON)**.
   * Показывает субмиллисекундное время работы (~0.15–0.19 мс), опережая базовый попиксельный Flood Fill более чем в 100 раз.

### 3. Алгоритм отсечения Кируса — Бека (`otsech.cpp`)
Параметрическое отсечение отрезка $P(t) = A + t(B - A)$, $t \in [0, 1]$ относительно произвольного выпуклого $N$-угольника:
* Вычисление внешних нормалей для каждой грани многоугольника.
* Классификация точек входа ($in$) и выхода ($out$) через знак скалярного произведения вектора направления отрезка и нормали грани.
* Нахождение пределов $[t_{in}, t_{out}]$ и расчет итоговых координат отсеченного отрезка.

## 🛠 Сборка и запуск

### Требования
* Компилятор с поддержкой **C++17** (Clang / Apple Clang, GCC)
* **CMake 3.20+**
* **SFML 3**
* **OpenCV 4** (для `main.cpp`)

### Установка зависимостей на macOS (Homebrew)
```bash
brew install sfml opencv cmake
```

### Сборка проекта
В корне репозитория создайте директорию сборки и запустите конфигурацию:

```bash
mkdir build && cd build
cmake ..
cmake --build .
```

*Примечание:* Для сборки основного бенчмарка в `CMakeLists.txt` указан `main.cpp`. Чтобы собрать другой файл (например, `otsech.cpp` или `ping-pong.cpp`), измените имя исходного файла в строке `add_executable(sfml_app <имя_файла>.cpp)` или добавьте дополнительный таргет.
